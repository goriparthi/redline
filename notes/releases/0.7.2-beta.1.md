The dashboard reaches back a quarter now, and a finding you have read can be told to go quiet.

### Added: 60 and 90 day ranges

The dashboard offered 7, 14 and 30 days, which was as far as Claude Code's own transcripts go
before it prunes them. The local store keeps entries for a year, so there is no longer a reason
to stop at a month. Both charts, both totals tiles and every panel follow the range, the same
as before.

The axis thins its labels as the range grows, so a quarter gets a date every fortnight rather
than printing one every five days and turning into a smear.

Worth knowing: **the long ranges start shallow.** The store only holds what it has seen, so
soon after installing, 60 and 90 days show the same data as 30 with more empty axis beside it.
That is the honest picture rather than a bug, and it fills in on its own as the store runs.

### Added: marking a finding as read

A finding restates something that is still in your transcripts, so left alone it sits on screen
for weeks after you have read it and stops carrying information. Each row now has a check mark
that hides that finding, and the count of what is hidden sits next to **Scan again**, where
clicking it brings them all back.

Two things about it are deliberate. The snooze **expires** rather than being permanent: after
`findingsSnoozeDays`, 14 by default, a finding that is still true is raised again, because
quietly dropping something real is a worse failure than repeating it. And dismissing **quiets
the menu bar line too**, since both surfaces read the same filtered report; a panel that has
emptied while the menu still claims four findings would be worse than having no dismissal.

### Changed: a door to the notification style

How long a notification stays on screen is macOS's to decide and there is no API for it, so
RedLine cannot hold a banner open for you. What you can change is the style: banners disappear
on their own, alerts stay until dismissed. **Settings ▸ Notification Style…** opens System
Settings on this app's own row, because nobody finds that setting by hunting for it.
