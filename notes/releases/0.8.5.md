Hovering a session in the Agents list no longer hides the actions you opened it to reach.

### Fixed: the path tooltip covered the session submenu

Each row under Agents carried a tooltip with the session's working folder. macOS opens a menu item's tooltip beside the pointer, which is exactly where that row's submenu appears, so the path landed on top of "Go to This Session" and made the first action hard to read or click. The tooltip is gone. The folder is still one hover away: the submenu lists the full path at its foot, and Copy Folder Path puts it on the clipboard.

### Install

    brew install --cask ./Casks/redline.rb

Or download the DMG below. Requires macOS Sonoma or later. Nothing changed since
0.8.5-beta.1, so if you are already on that build this is the same app with a stable
version number.
