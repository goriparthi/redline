Percentages that stayed put, a beta channel, and Cmd+Q that no longer quits the menu bar.

### Fixed: the Claude percentages kept vanishing

Claude Code hands its statusline a `rate_limits` block with every window set to null on any draw that made no API call. The feeder wrote that over the last real reading, so the percentages disappeared and the menu bar dropped to a red "Connect" until the next real draw, sometimes twenty minutes later. The feeder now writes only a payload that actually carries a window.

RedLine also reads that state honestly now. A feed that is installed but has no reading yet is waiting on Claude Code, not a missing source, so it shows a grey ellipsis rather than red "Connect", the menu says "Waiting for Claude Code to report usage", and a quiet feed keeps its last windows drained by age instead of blanking. The "Claude percentages are off" row no longer appears when the feed is already set up.

### Added: a beta channel

Set `"updateChannel": "beta"` in `~/.config/redline/config.json` to receive prerelease builds, or install the beta cask. Stable stays the default and never sees a prerelease.

### Changed: Cmd+Q in the dashboard

Closing the dashboard with Cmd+Q used to quit the whole app, taking the menu bar item with it. It now closes the window and leaves RedLine running. The app menu is visible whenever a window is open.

### Install

    brew install --cask ./Casks/redline.rb

Or download the DMG below. Requires macOS Sonoma or later.
