Clicking an agent now takes you to the tab it is running in, not just to the terminal app it is somewhere inside.

### Fixed: focus goes to the session, not the app

In beta.2 the row action raised iTerm2 and left you to find the tab yourself, which on a
machine running ten sessions is barely better than not clicking at all.

A session record names the app but not the window. The process does have a controlling
terminal, though, and both iTerm2 and Terminal publish the tty of every tab, so the tty is
the join between the two. RedLine reads it from the kernel and asks the terminal to select
that tab. Split panes work the same way, because iTerm2 reports a tty per pane rather than
per tab.

The app is raised first and unconditionally, before any of that is attempted. So if the
terminal cannot say where a session is, you still land in the right application rather than
nowhere, and the menu item says which of the two it is about to do: **Go to This Session in
iTerm2** when it can reach the tab, plain **Focus Ghostty** when it cannot. Ghostty, WezTerm
and Alacritty expose no tab API at all, so those keep the old behaviour, stated honestly.

macOS asks once for permission to control your terminal, the first time you use it. Decline
it and the feature degrades to raising the app, which is exactly where beta.2 was. This is
the only Apple event RedLine sends.

### Fixed: the two build paths signed differently

`scripts/bundle.sh` signed the app with no entitlements file at all, while the Xcode path
signed with `Resources/Redline.entitlements`. The two builds therefore ran with different
capabilities, which is the kind of difference that only shows up as a feature silently doing
nothing in one of them. Both paths now sign with the same file.

### Added: a written deploy procedure

`docs/DEPLOY.md` covers the whole thing: the five artifacts that have to agree on a version,
the order they have to happen in, the promotion gate, and what to do when a release goes out
wrong. A DMG sitting in `dist/` is a build nobody can install, so `make dmg` now says so
loudly on every exit path, and the release script ends on the cask step instead of trailing
off after publishing.
