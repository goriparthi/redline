The session window now carries a figure on the dashboard, and the cadence panel says which providers it is counting.

### Added: the session window on the dashboard

The dashboard drew the **Session (5h)** rail but gave no volume for that window, so a
percentage sat there with nothing to be read against. A **Last 5 hours** tile now sits beside
Today, with tokens and estimated cost, matching what the menu has always shown.

Expect it to read the same as Today for the first five hours of a day, because for those hours
it is the same window. They part company as the day goes on.

There is deliberately no fixed seven day tile. The range buttons already offer 7 days, and a
tile pinned to a week beside a range set to a quarter would contradict the window named next
to it, which is the sort of mismatch the rest of this panel is careful to avoid.

### Added: the rolling day's total

The **Last 24 hours** panel drew the shape of the day without ever saying what it added up to.
Its header now carries the total and the estimated cost for that rolling day. It went in the
header rather than becoming a sixth tile, because that panel already names the window.

### Changed: the cadence panel says it counts every provider

Every other panel narrows to the focused track. The cadence panel does not, and its header now
says **all providers** when a track is focused rather than leaving you to assume it had
narrowed too.

It is not scoped because scoping it would be wrong rather than merely narrower. A run is
measured from the gaps between records, so filtering to one provider inserts gaps that were
never idle time: three hours of alternating between Claude and Codex would be reported as
several short runs instead of one long one. The reason is written down next to the code so it
does not get quietly "fixed" later.
