Fixes a settings window that drew itself wrong on macOS 26, and refreshes every screenshot in the README and on the site to the interface 0.8.0 actually ships.

### Fixed: the settings window drew over itself

On macOS 26 the settings window put its sidebar on top of the content instead of beside it, and
a sidebar toggle floated over the panel with the section heading clipped off behind it. It was
usable, but it looked broken, which is worse than usable.

The cause was the container rather than the content. `NavigationSplitView` expects to own a
toolbar in the window's titlebar, and this window has no toolbar for it to own, so the toggle it
installs had nowhere to go and the detail pane slid under both it and the floating sidebar.

Settings is now two plain columns: a fixed sidebar, a divider, and the panel. Six fixed sections
gain nothing from a collapsible sidebar, and the window now looks the same on every macOS
version RedLine supports rather than depending on what the current one does with a split view.

### Changed: the threshold sliders take their own colour

The Approaching and At the limit sliders were drawn in the system accent, sitting directly above
preview rails in amber and red showing the same two numbers. They now carry the colour of the
threshold they set, so the control and the thing it controls match.

### Changed: the screenshots are the app you get

Every dashboard image in the README and on the homepage predated the redesign, and the menu bar
shot still had a 0.6.0 version string in it. The dashboard, the provider cards, the light
appearance, a provider in detail and two settings sections are all recaptured from 0.8.1.

The widget images and the menu bar dropdown are the ones still to be redone. Both need a human
at the keyboard: widgets have to be placed on a desktop, and a second copy of RedLine cannot get
a menu bar slot to open its dropdown into. They are the pre-0.8.0 interface until then, and they
are the only images on either page that are.

### Changed: the documentation says what ships

Every settings path in the README pointed at a submenu that 0.8.0 replaced, so all of them now
name a section of the settings window instead. The section explaining that RedLine deliberately
avoids vendor logos has been rewritten, because as of 0.8.0 it does not: it uses the real
provider marks, monochrome and unaltered, with the licences shipped inside the app. The decision
log records the reversal and which half of the original reasoning still holds.
