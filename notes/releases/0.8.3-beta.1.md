The update line in the menu bar dropdown now carries the GitHub mark and opens the repository when you click it.

### Added: the update line goes to the source

Nothing in the dropdown said where RedLine comes from, and the only way to the repository was to open settings and find the link in About. The line that already reports which version you are on is the natural place for it, since that line is the one thing in the menu that is about the build rather than about your usage.

It now sits behind the GitHub mark and opens the repository page in your browser. That holds for every state the line reports, so a development build, a failed check and an available update all lead somewhere useful rather than only the up to date case.

The mark is Simple Icons vector data under CC0, template rendered so it takes the menu's own colour in light and dark. It identifies GitHub and is not RedLine branding; the notices file records it alongside the provider marks.

### Install

    brew install --cask ./Casks/redline-beta.rb

Or download the DMG below. This is a prerelease; the stable channel will not offer it.
Requires macOS Sonoma or later.
