On Windows, Install and Relaunch no longer leaves you with RedLine closed and no update when the install does not go through.

### Fixed: a failed Windows update quit RedLine and never brought it back

Install and Relaunch quits RedLine, then a hidden helper runs the new MSI silently. If Windows Installer was busy with another install at that moment, such as a winget or Windows Update package, the helper ran once, gave up without a word, and left nothing running: no tray icon and no error. The helper now waits for the other install to finish, for up to five minutes, before trying again. If the install still does not leave RedLine running, it starts the copy you already had. Every update now writes a verbose installer log to `%USERPROFILE%\.local\share\redline\update-msi.log`, and the next launch records the result in diagnostics and shows a failure in the menu.

This takes effect from the update after this one, because the version you are running is the one that installs the next. If 0.8.6 left RedLine closed, start it from the Start menu, or run the MSI below.

### Install

Windows: download `RedLine-0.8.7-x64.msi` below and double-click it, or use **Install Update...** in the tray.

macOS: nothing changed for the Mac in this release, and there is no DMG for it. Stay on 0.8.6.
